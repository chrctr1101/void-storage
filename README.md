# void-storage
Make your computer work like reserve storage

This simple program will take care about your USB device. Program will do automaticly mount USB.
Be sure that you insert USB device before launch program.
Don't remove USB until program ends

Program works with USB as an solid device. Use USB device as a bridge between PCs.
You can copy/move ALL data from USB device
	    copy/move directory to USB device
		delete local directories
		format USB device
		rename directories in local evnironment
